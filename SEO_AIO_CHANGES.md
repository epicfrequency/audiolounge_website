# SEO and AI optimization changes

This package is based on the current GitHub v4.1 layout and does not redesign the homepage.

## Added

- `SoftwareApplication` JSON-LD
- `WebSite` JSON-LD
- FAQ page with `FAQPage` JSON-LD
- `llms.txt`
- `llms-full.txt`
- richer Open Graph and Twitter Card metadata
- crawler-friendly `robots.txt`
- sitemap with FAQ, last modified dates, priorities, and change frequency
- `site.webmanifest`
- `.well-known/security.txt`
- breadcrumb structured data for Support and Privacy
- direct FAQ links in page footers

## Preserved

- Existing homepage layout and CSS
- Existing animation behavior
- Original PNG screenshots and icon
- Existing Cloudflare Worker configuration
