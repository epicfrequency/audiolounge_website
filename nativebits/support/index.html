Getting started

Before you begin

Have these ready

  • Your DSD source files in a folder you can access on your Mac.
  • Album and track information you want written into the project.
  • Enough free storage for the completed disc image and temporary build files.

Create a new project, choose its destination, and add your source files. Arrange the tracks in their intended playback order, complete the album and track information, then open Validation before starting the build.

Project checks

When validation finds an issue

NativeBits identifies the part of the project that needs attention. Select the reported item, review its explanation, and correct the related source file, metadata, or disc setting. Run validation again after making changes.

A source file is unavailableReconnect the drive or storage location, then locate the file again in the project.
Tracks use different formatsReview the format and channel information shown for each track and replace incompatible sources.
The build needs more spaceChoose a destination with enough free capacity for both temporary data and the completed image.
